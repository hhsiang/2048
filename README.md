# 2048
An afternoon project: building a version of 2048 to run in the console in R.

Recently, on the plane to a friend's wedding, I re-discovered 2048 in the in-flight entertainment. I remember playing this game during a summer back from college, poolside, when I was working a swim instructor in some dingy gym.

It seemed like a fun little project one afternoon while my partner was working, so I coded it up. Just base R (4.6.1), running in the console. To play, just run 2048.R and enjoy!
